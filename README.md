# Vicky Portfolio Website

A responsive and modern portfolio website built with React, Tailwind CSS, JavaScript, and Vite.

## Features

* Responsive design for mobile, tablet, and desktop
* Modern and clean user interface
* About Me section
* Skills showcase
* Projects section
* Contact information
* Resume download option

## Technologies Used

* React
* Tailwind CSS
* JavaScript
* Vite
